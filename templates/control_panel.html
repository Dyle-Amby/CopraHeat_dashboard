Reset to idle Clears a completed or aborted batch so a new one can start

Abort batch

Stops the batch in software. Heaters go off at once; a hot chamber is purged through cooldown before the batch is marked aborted, so the fans may keep running.

This is not an emergency stop. An e-stop has to cut heater and motor power in hardware, independent of the Pi and this page.
